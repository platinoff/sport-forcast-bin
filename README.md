# sport-forcast

<p align="center">
  <img src="portable.svg" alt="Five football markets and a portable download: Windows exe and Linux binary. No install." width="880">

One file. No installer. No account.

The journal lists Ukraine, Poland, England, Canada, and Germany. The pick is the side with more points per match on that league's table. It is not a price.

## Download

- [Windows, `sport-forcast.exe`](https://github.com/platinoff/sport-forcast-bin/releases/download/v0.2.0/sport-forcast.exe)

Run the file. It listens on `127.0.0.1:9741`. Open `http://127.0.0.1:9741/?lang=uk`.

This page is the program only. The source stays in a private repository.
